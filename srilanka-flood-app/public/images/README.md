# Images Directory

## Sri Lanka Flood Disaster Image

Place your Sri Lanka Flood Disaster image here with the filename:
- `sri-lanka-flood-disaster.jpg` (or `.png`, `.webp`)

### Recommended Image Specifications:
- **Format**: JPG, PNG, or WebP
- **Dimensions**: 800x400 pixels (or similar aspect ratio 2:1)
- **File Size**: Under 500KB for optimal loading
- **Content**: Should show Sri Lanka flood disaster relief scene

### How to Add Your Image:

1. Save your image file as `sri-lanka-flood-disaster.jpg` (or `.png`)
2. Place it in this `public/images/` folder
3. The form will automatically use your image
4. If the image is not found, it will fallback to a default image

### Alternative Image Names:
The form will also check for these filenames:
- `sri-lanka-flood.jpg`
- `flood-disaster.jpg`
- `flood-relief.jpg`
